# Внешность — версия 0.2

Изменение отвечает на три замечания: одинаковые фигуры с фотографиями на лицах, исходные фотографии в карточках и слишком условные пропорции/оформление.

## Игровые модели

На лицах нет исходных или сгенерированных портретных текстур. Сходство задаётся геометрией и цветом материалов. Для каждого героя отдельно заданы ширина/высота головы, сужение челюсти и подбородка, щёки, выступ и ширина носа, расстояние между глазами, разрез глаз, цвет радужки, рот, уши, причёска, ширина корпуса и плеч. Эти значения — художественные параметры, не биометрические измерения.

| Герой | Черты, использованные в модели |
|---|---|
| Лайка | Удлинённое овальное лицо, густые тёмные волнистые волосы, светлые глаза, заметный нос, широкая улыбка |
| Кемпиль | Более округлый контур овального лица, тёмная прямая чёлка, тёмные глаза, заметные уши |
| Габар | Узкое вытянутое лицо, суженный подбородок, каштановые пряди, светлые глаза |
| Демидок | Более угловатая челюсть, короткие светлые волосы и неровная чёлка, светлые глаза |
| Азиом | Более широкие щёки и подбородок, короткие волосы с направлением набок, тонкие круглые очки |
| Пинив | Более широкое овальное лицо, светло-каштановые волосы с неровной чёлкой, светлые глаза |
| Аскар | Узкий нижний контур лица, более крупный разрез тёмных глаз, тёмные брови и приподнятые волосы |

Затылки и скрытые участки лица интерпретированы: исходные фотографии не дают полного обзора. Тела различаются по игровому росту и ширине, но не являются точной реконструкцией фигур с фотографий. Модели стилизованы; качество портретов выше детализации игрового 3D.

Руки и ноги состоят из шарнирных частей; при движении сгибаются локти и колени. Кисти имеют отдельные пальцы. Ткань формы создаётся процедурно. Статические части каждого сустава объединяются по материалу, чтобы уменьшить число вызовов отрисовки.

## Карточки

Семь отдельных изображений созданы встроенным инструментом генерации изображений. Исходные фотографии задавали внешность; портрет Лайки использовался как образец света и формы для остальных. Для Азиома исходный MPO/JPEG был преобразован в обычный RGB PNG для совместимости инструмента; лицо при этом не редактировалось вручную.

Все финальные портреты находятся в `assets/portraits/`. Полный набор запросов — `portrait-prompts.json`. Изображения преобразованы в JPG 768×1152 для загрузки на телефонах. Карточки, маленькие портреты в меню, портрет активного игрока и Аскар используют новые изображения. Исходные фотографии исключены из распространяемого архива.

## Окружение

Обновлён баланс дневного света, оттенок неба, фактура покрытия, металлические элементы и прозрачные щиты с рамками. Игровые правила, рейтинги и суперприёмы не менялись.
